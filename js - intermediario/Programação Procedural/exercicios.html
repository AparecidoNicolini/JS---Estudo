📚 Lista de Exercícios - JavaScript Iniciante

1. Somar dois números

Crie dois inputs para o usuário digitar dois números e um botão que, ao clicar, mostre a soma deles na tela.

2. Contador de cliques

Crie um botão que, toda vez que for clicado, aumente um número mostrado na tela.

3. Verificar se o número é par ou ímpar

O usuário digita um número e, ao clicar no botão, aparece na tela se ele é par ou ímpar.

4. Mostrar mensagem ao digitar no input

Crie um input e use o evento keyup para mostrar na tela, em tempo real, o que a pessoa está digitando.
